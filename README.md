**Digital Dragons – News Platform**<br>
A full-stack news platform that delivers real-time news from Sweden and around the world 
using external news APIs and Azure AI services.

**Features**<br>
• Real-time data retrieval from external APIs.<br>
• Search and filter articles by keywords and categories.<br>
• Article visit tracking using cookies to manage user access and engagement.<br>
• Voice search using Azure Speech-to-Text.<br>
• Text-to-Speech functionality for accessible content consumption.<br>
• Real-time article translation using Azure Translator.<br>
• Role-Based Access Control (RBAC) implemented with ASP.NET Core Identity.<br>
• Responsive user interface for desktop and mobile devices.<br>
• Developed using Agile and Scrum methodologies.<br>

**Technologies:**
ASP.NET Core, C#, Azure Cognitive Services, Azure Translator, REST APIs, SQL Server, HTML, CSS, JavaScript, Bootstrap.
